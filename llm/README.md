# Dossier `claude/`

Ce dossier contient les grandes lignes à connaître pour continuer à travailler sur ce cours avec Claude Code, peu importe la machine (bureau, maison, etc.).

**Pourquoi ce dossier?** La mémoire personnelle de Claude Code (`~/.claude/projects/.../memory/`) et l'historique des conversations sont **locaux à chaque machine** — ils ne se synchronisent pas. Ce dossier, lui, est versionné avec le reste du cours : un `git pull` sur une autre machine suffit pour tout récupérer.

## Dans une nouvelle session, lire dans l'ordre

1. [etat_du_projet.md](etat_du_projet.md) — où on en est, qu'est-ce qui reste à faire.
2. [conventions.md](conventions.md) — comment le code/contenu est structuré, pour rester cohérent.
3. [preferences.md](preferences.md) — comment Nick aime travailler avec Claude.

## Mise à jour

Ces fichiers sont volontairement courts (les « grandes lignes », pas une documentation exhaustive). Après une session de travail significative, vaut mieux les mettre à jour brièvement plutôt que de les laisser devenir obsolètes.
